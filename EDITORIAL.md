# Редакционные предпочтения

- Визуальный формат: изображения на первом месте, короткая подпись на 40–70 слов.
- По возможности 2–3 содержательных изображения: общий вид и детали, без повторов ради количества.
- Приоритет — официальные сайты музеев, коллекций, архивов и культурных учреждений. Вторичные материалы допустимы, если ссылаются на проверяемые официальные первоисточники; факты сверять с ними.
- В публикации указывать название первоисточника и авторство/кредит изображения, соблюдать условия использования. URL в публикации не добавлять: ссылки хранить в проекте для проверки фактов.
- Для существующего поста сохранять ссылку при редактировании; дополнительные детали можно публиковать ответом к нему.
- Облачное расписание: каждый час круглосуточно. Ежедневное локальное расписание Codex отключено.
- Рубрики чередуются строго по успешным публикациям: история моды → архитектура → культурные путешествия → женщины в искусстве → картина дня. Сбой не продвигает очередь; не заменять отсутствующий материал другой рубрикой.
- «Женщины в искусстве» — работы художниц, а не любые женские портреты. «Культурные путешествия» — культурные места и их исторические изображения; не выдавать их за современные туристические рекомендации.
