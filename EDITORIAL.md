# Редакционные предпочтения

- С 7 ноября 2026: мода — актуальные сезоны; архитектура, живопись и художницы — проекты и произведения XXI века. Исторические музейные карточки больше не подставлять в эти четыре рубрики автоматически.
- Современная очередь `cloud/queue/modern-*.json`: индивидуально проверенные дата, первоисточник и изображение. Для моды перепроверять источник через 60 дней, для остальных направлений — через год. При исчерпании очередь требует пополнения, исторический резерв не используется.
- Для произведений современных авторов проверять разрешение на само произведение, а не только лицензию фотографа. Приоритет — авторская публикация или подтверждённое разрешение правообладателя. Портрет художницы явно обозначать как портрет; факты о практике брать у музея или автора.
- Снимок другого сезона или бренда нельзя выдавать за показ текущей коллекции. Если он лишь иллюстрирует приём, подписывать это явно. Не использовать фото, по которым нельзя рассмотреть обсуждаемую деталь.

- Визуальный формат: изображения на первом месте, короткая подпись на 40–70 слов.
- По возможности 2–3 содержательных изображения: общий вид и детали, без повторов ради количества.
- Приоритет — официальные сайты музеев, коллекций, архивов и культурных учреждений. Вторичные материалы допустимы, если ссылаются на проверяемые официальные первоисточники; факты сверять с ними.
- В публикации указывать название первоисточника и авторство/кредит изображения, соблюдать условия использования. URL в публикации не добавлять: ссылки хранить в проекте для проверки фактов.
- Для существующего поста сохранять ссылку при редактировании; дополнительные детали можно публиковать ответом к нему.
- Расписание: один блок из 100 публикаций ежедневно в 22:30 по Москве (19:30 UTC) через GitHub Actions, без Vercel. Каждый материал считается одной публикацией, даже если содержит альбом из нескольких изображений.
- В полном ежедневном блоке: стиль и история моды — 15; архитектура и интерьер — 15; культурные путешествия — 15; женщины в искусстве — 15; живопись — 15; книги, кино и визуальные истории — 10; викторины — 15. Подтверждённые публикации блока сохраняются по московской дате; повторный запуск продолжает незавершённый блок до 100, не отправляя заново уже подтверждённые материалы. Не отправлять дневной блок раньше 22:30.
- Фото обязательно у каждого материала. Недоступное изображение нужно заменить тематическим с проверенной лицензией; отправка статьи одним текстом не допускается.
- Рубрики чередуются по успешным публикациям: стиль → архитектура/интерьер → путешествия → художницы → живопись → книги/кино → викторина. В цикле из 20 слотов книги появляются дважды, остальные рубрики трижды. Сбой не продвигает очередь; не заменять отсутствующий материал другой рубрикой.
- «Женщины в искусстве» — работы художниц, а не любые женские портреты. «Культурные путешествия» — культурные места и их исторические изображения; не выдавать их за современные туристические рекомендации.
- Аудитория — современные девушки и женщины с разными интересами. Связывать материал с личным стилем, домом, чтением, творчеством, отдыхом и культурным кругозором; не сводить интересы женщин к внешности или покупкам.
- Для редакционных постов: конкретная деталь, проверенный факт и понятный повод сохранить материал. Избегать одинаковых вступлений и длинных шаблонных упражнений. Исторический предмет может давать современную идею, но не объявляется актуальным трендом без проверки.
- Разнообразие: не повторять изображение или ту же работу под другим номером; не ставить одного автора подряд; не более двух работ одного автора в последних 100 публикациях. Не более одной цианотипии в последних 100: серия с одинаковым голубым фоном не должна занимать выпуск.
- Викторины публиковать с фото, проверенным ответом и перемешиванием вариантов. Правильный ответ не закреплён на первом месте.
- Копии древних росписей датировать отдельно от оригинала: художница XX века не могла создать работу в древнеегипетскую эпоху.
