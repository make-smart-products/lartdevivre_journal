## Облачная публикация

Режим с 8 ноября 2026 года: 15 публикаций ежедневно в 22:30 МСК через GitHub Actions.
Четыре направления: современная мода → современная архитектура → известные картины →
модели, актрисы и знаменитости. Викторины, путешествия, книги/кино и отдельная рубрика
художниц отключены. Предыдущие карточки перенесены в `cloud/archive/2026-11-08-retired-queue`;
публикуется только активная очередь `cloud/queue/modern-*.json`.

Добавлено 16 проверенных статей с индивидуальными подписями и фотографиями: по четыре
на направление. Это следующий блок из 15 и одна дополнительная карточка; постоянный
резерв ещё не сформирован. Самостоятельный облачный ИИ-редактор пока не подключён.

Перед отправкой проверяется наличие всего оставшегося дневного блока, действительность
редакционной проверки, права на изображения и отсутствие повторов. Проверка `dry_run`
просматривает по три последовательных материала каждого активного направления и права
бота без публикации. Отсутствующий материал не заменяется постом отключённой рубрики.

`python scripts/configure_cloud.py dispatch --publish --now` явно запускает сегодняшний
блок немедленно. Подтверждённые материалы учитываются в том же дневном лимите из 15,
поэтому плановый вечерний запуск их не дублирует. Время 22:30 остаётся без изменений;
GitHub Actions может задерживать начало запуска.

`cloud/state.json` хранит использованные экспонаты, подтверждённые сообщения и
незавершённую попытку. Сначала программа сохраняет резервирование в GitHub, потом
отправляет в Telegram и сохраняет квитанцию. Если ответ потерян, следующая отправка
блокируется до ручной проверки канала. Это предотвращает дубли. Коммиты состояния
также поддерживают активность репозитория для планового запуска GitHub.

В разделе Actions можно выполнить ручную проверку с `dry_run=true`. Она проверяет
источник и подпись без публикации. Для остановки достаточно отключить workflow.
Ошибки видны в Actions; никакого отдельного платного сервера не требуется.

## Разовая публикация подготовленных 100 материалов

`python scripts/publish_collection.py prepare` собирает локальный план для конкретного
пакета LDV-001—LDV-100: 85 коротких статей и 15 интерактивных викторин. Изображения
берутся из официальных каталогов Met и Art Institute of Chicago с отметками
Public Domain/CC0; музейные иллюстрации подписываются отдельно. URL остаются
только в локальном плане. Этот пакет не заменяет ежедневную очередь.

`python scripts/publish_collection.py publish` отправляет пакет в канал без
звуковых уведомлений. Скрипт использует Telegram из локального `.env` и сохранённый
в Git Credential Manager доступ к GitHub. Состояние `editorial_batches` и
резервирование в `cloud/state.json` позволяют продолжить подтверждённый пакет без
повторов. Успешный ответ сначала сохраняется в локальный `delivery-journal.jsonl`,
затем в GitHub. При неизвестном результате отправка останавливается. Фото обязательно:
при недоступном изображении отправка останавливается до его замены; отправка одним
текстом запрещена. Сводные квитанции — в materials/imported/mass-receipts.json.

`scripts/repair_collection_photos.py` подбирает свободно лицензированные фотографии
и добавляет их к существующим статьям через `editMessageMedia`, сохраняя адреса
публикаций. Кандидаты требуют редакторского выбора в локальном photo-selections.json.
Авторство и лицензия указываются в подписи, адрес источника сохраняется в квитанции.
